# 🎭 Pet-project: автоматизация тестирования SauceDemo на Playwright

Учебный проект для портфолио — фреймворк автотестов для интернет-магазина [SauceDemo](https://www.saucedemo.com/).

## 🚀 Стек технологий

- **Playwright** — кросс-браузерная автоматизация (Chrome, Firefox, Webkit)
- **TypeScript** — типизация и современный JS
- **Page Object Pattern** — лёгкая поддержка тестов
- **GitHub Actions** — CI/CD, автотесты при каждом пуше

## 📋 Что умеют тесты

| Функция | Описание |
|---------|----------|
| ✅ Логин | Проверка успешного входа, ошибок, валидация |
| ✅ Корзина | Добавление, удаление, проверка количества товаров |
| ✅ Оформление | Заполнение формы, проверка суммы, финальное подтверждение |
| ✅ Сквозной сценарий | Полный путь пользователя от логина до "спасибо за заказ" |

## 🔧 Запуск тестов локально

```bash
# Установка зависимостей
npm install

# Установка браузеров Playwright
npx playwright install

# Запуск всех тестов (без UI)
npm test

# Запуск с открытым браузером (headed)
npm run test:headed

# Только smoke-тесты
npm run test:smoke

# Только регрессионные тесты
npm run test:regression
