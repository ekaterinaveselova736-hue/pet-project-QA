# 🎭 Playwright Test Automation Framework for SauceDemo

Профессиональный фреймворк для автоматизации тестирования интернет-магазина SauceDemo.

## 🚀 Технологии

- **Playwright** - кросс-браузерная автоматизация
- **TypeScript** - типобезопасный код
- **Page Object Pattern** - поддерживаемость тестов
- **GitHub Actions** - CI/CD пайплайн

## 📋 Требования

- Node.js 16+
- npm 8+

## 🔧 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/playwright-saucedemo-framework.git

# Установить зависимости
npm install

# Установить браузеры Playwright
npx playwright install
